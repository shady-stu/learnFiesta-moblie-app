# LearnFiesta Application

This directory contains the runnable Expo and React Native application. See the [repository README](../README.md) for the product overview, verified features, architecture, environment variables, testing scope, team attribution, and current limitations.

## Quick Start

```bash
npm ci
npm start
```

A local `.env` with the Firebase variables documented in the repository README is required for data-backed features.

## Available Scripts

```bash
npm start
npm run android
npm run ios
npm run web
npm run lint
npm test -- --runInBand
```

`npm run start:offline` is Windows-specific because its script uses Windows `set` syntax.
